# Nicko — Espaço pessoal

Uma aplicação pessoal para organizar o cotidiano, cultivar hábitos e avançar em pequenos passos.

## Publicação
O projeto é estático e pode ser hospedado no GitHub Pages, Cloudflare Pages ou outro serviço de hospedagem estática. O ponto de entrada é `index.html`.

## Funcionalidades
- Painel diário com prioridades, andamento e sugestão de próximo passo.
- Cadastro, conclusão, filtro e remoção de tarefas.
- Acompanhamento diário de hábitos e sequência de prática.
- Projetos com progresso, prazo e próxima ação.
- Caixa de ideias com conversão de ideias em tarefas.
- Revisão semanal.
- Temporizador de foco de cinco minutos.
- Exportação e restauração de backup em JSON.
- Layout responsivo e suporte básico a PWA/offline.

## Armazenamento
Os dados são salvos no armazenamento local do navegador deste dispositivo. Não há sincronização automática entre dispositivos. Use a opção de backup regularmente.

## Fotografias e fontes
As fotografias e as fontes externas são carregadas pela internet. A aplicação continua utilizável sem elas, mas a atmosfera visual pode ficar reduzida offline.
